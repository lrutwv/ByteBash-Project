# BYTEBASH 

A small indie game studio website created as a collaborative practice project.

## About the Project

ByteBash is a fictional indie game studio website designed around a fun, colorful, pixel-art-inspired aesthetic.

The website includes:

*  Home
*  Games
*  About
*  Developer Blog
*  Community

The design was first created in **Figma** and then developed using **HTML and CSS**.

## Technologies Used

* HTML5
* CSS3
* Figma

No JavaScript was used in this project.

## Collaboration

This website was created as a **collaborative project**. We worked together on the design and development process, from creating the Figma layouts to implementing the website with HTML and CSS.

## Purpose

This project was created primarily for **practice and learning**.

Our main goals were to practice:

* Creating website layouts in Figma
* Translating a design into HTML and CSS
* Building multiple connected pages
* Using responsive CSS for different screen sizes
* Working with Git and GitHub as a team
* Improving our understanding of web design and front-end development

## Design

The visual style was inspired by:

* Pixel-art games
* Retro game interfaces
* Neon colors
* Indie game websites
* Developer journals and game dev blogs

The website uses a dark background with neon purple, lime, and cyan accents to create a playful game-development atmosphere.
